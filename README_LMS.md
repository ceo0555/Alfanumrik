## 🎨 Color Palette

### Course Gradients
```css
Blue → Indigo    /* Physics, Technology */
Purple → Pink    /* Arts, Literature */
Emerald → Teal   /* Biology, Environment */
Orange → Red     /* Chemistry, Energy */
Cyan → Blue      /* Mathematics, Logic */
Fuchsia → Purple /* Special Topics */
```

### Grade Colors
```
🟢 90-100% - Emerald (Excellent)
🔵 80-89%  - Blue (Good)
🟡 70-79%  - Yellow (Satisfactory)
🟠 60-69%  - Orange (Needs Improvement)
🔴 0-59%   - Red (Requires Attention)
```
